# 🇬🇧 Grammar In Use - 핸즈프리 영국 영어 오디오 쉐도잉 튜터

> **유튜브 영상 시청 없이 순수 고음질 영국 원어민 사운드로만 학습하는 오디오 중심 쉐도잉 서비스**  
> 최초 **[▶ 핸즈프리 자동 학습 시작]** 버튼을 딱 한 번만 누르면, **마우스/키보드 조작 없이 귀로 듣고 입으로 말하기만 하면 무한 자동 순환**됩니다!

---

## 🎯 주요 개편 사항 (Audio-First & Hands-Free)

1. **유튜브 영상 시청 불필요 (순수 오디오 팟캐스트 방식)**
   - 유튜브 영상 화면을 제거하고, 화면 중앙에 큼직한 영문/한글 스크립트와 역동적인 오디오 파형(Visualizer)만 집중 배치.
   - 로컬 고음질 원어민 음원 (`audio/chapter1.m4a`, `chapter2.m4a`) 탑재로 0ms 즉각 재생.

2. **문장 끝 정확한 정지 (다음 문장 침범 차단)**
   - 문장과 문장 사이의 경계에 **0.35초 안전 여유 간격**을 적용하여 다음 문장의 첫 단어가 새어 나오는 현상을 완벽 차단.
   - 상단 툴바에서 [정지 여유: 0.2s / 0.35s(권장) / 0.5s] 직접 조절 가능.

3. **완전 자동 핸즈프리(Hands-Free) 무한 루프**
   - **Step 1 (원어민 듣기)**: 현재 문장의 영국 원어민 발음 자동 재생.
   - **Step 2 (챠임벨 안내)**: 재생 종료 0.3초 후 부드러운 "딩~" 안내음과 함께 마이크 자동 ON.
   - **Step 3 (말하기 & 침묵 감지)**: 사용자가 따라 말하고 말을 멈추면 자동으로 녹음 종료 & 채점.
   - **Step 4 (결과 & 자동 연속 진행)**:
     - **80% 이상 통과 시**: 축하 효과음("딩동댕~") ➔ **1.2초 후 자동으로 다음 문장으로 넘어가서 다시 Step 1 자동 재생**!
     - **80% 미만 시**: 재시도 알림음 ➔ 해당 문장을 1회 더 자동 재생하고 다시 기회 제공 (2회 시도 후 자동 다음 문장 이동).
