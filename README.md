## 🎯 주요 기능 및 특징

1. **산뜻한 고대비 밝은 테마 (Light Theme 기본 탑재)**
   - 눈이 편안한 밝은 화이트 테마에 영문이 선명하게 돋보이는 모던 BBC/Apple 디자인.
   - 우측 상단 [☀️ 라이트 / 🌙 다크] 버튼으로 1초 만에 테마 전환 가능.

2. **100% 무클릭 핸즈프리(Hands-Free) 무한 자동 순환**
   - **[▶ 핸즈프리 자동 학습 시작]**을 1번 누르면:
     - 🎧 원어민 발음 듣기
     - ➔ 🔔 "딩~" 안내 챠임벨과 함께 마이크 자동 ON
     - ➔ 🗣️ 따라 말하기 & 자동 침묵 감지
     - ➔ 🎉 80% 이상 합격 시 성공음과 함께 1.2초 후 다음 문장으로 자동 이동하여 계속 재생!

3. **칼같은 문장 분리 (다음 문장 침범 차단)**
   - 문장과 문장 사이 0.35초 안전 여유 간격을 두어 다음 문장이 새어나가지 않고 정확하게 멈춥니다.
   - [정지 여유: 0.2s / 0.35s(권장) / 0.5s] 직접 조절 가능.
